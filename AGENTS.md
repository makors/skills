# AGENTS.md

- One skill = one folder with a `SKILL.md` (frontmatter: `name`, `description`).
- Put it in the right category: `apps/`, `design/`. Add a new one only if nothing fits.
- Keep skills short. Under ~60 lines. Commands over prose.
- Test every command before you commit it.
- No secrets, IPs, serials or access codes. Use env vars.
- Keep this file short too.
